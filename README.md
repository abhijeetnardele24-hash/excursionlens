# ExcursionLens

> **From a temperature alert to an evidence-backed investigation.**

An evidence-first agent for cold-chain temperature excursion analysis that combines deterministic sensor truth, live Tavily authoritative research, and NVIDIA Nemotron causal hypothesis synthesis through Nebius Token Factory.

Built for the **Nebius x NVIDIA Global AI Hackathon** (Track: *Best Apps and Agents*, Bonus: *Best Use of Tavily*).

---

### Core Principles

1. **Deterministic Sensor Truth:** Sensor measurements, time-series windows, and min/max duration calculations are purely deterministic. AI never invents or alters physical observations.
2. **Authoritative Research Grounding:** Live Tavily queries against verified domain allowlists (`cdc.gov`, `fda.gov`, `who.int`) provide clinical and regulatory guidance context.
3. **Competing Hypotheses & Skeptic Loop:** NVIDIA Nemotron models synthesize competing causal hypotheses, followed by an adversarial skeptic pass that attacks assumptions and identifies contradictions.
4. **Human Review Boundary:** ExcursionLens produces review packets for qualified quality professionals. It never makes autonomous product release or disposition decisions.
